# Jiatrix
## One terminal agent, three modes.
    - python jiatrix.py secretary   memory + tasks + web + files   (default)
    - python jiatrix.py dev         coding agent for the current repo
    - python jiatrix.py sysadmin    Arch/Manjaro system control

Env: AGENT_MODE, AGENT_MODEL, AGENT_CTX, AGENT_OWNER, AGENT_TIMEOUT, AGENT_NOTHINK
Launch it from the folder you want it to work in.

## Installation
There's requirements.txt file to install libraries
    - pip install -r requirements.txt
